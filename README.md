# Pixiv Viewed Marker

Chrome MV3 扩展，用本地记录标记 Pixiv 已访问作品，并增强作品页浏览体验。

## 功能

- 已访问作品标题变色。
- 可选图片遮罩。
- 可选隐藏已访问作品卡片。
- 支持从 Chrome 历史初始化导入 Pixiv 访问记录。
- 支持按 Pixiv 页面 URL 排除标记渲染，例如收藏页不变色、不遮罩、不隐藏。
- 支持 JSON 备份导出、合并导入、清空记录。
- 作品页右侧显示作者作品速览面板，`2 x 3` 网格分页浏览。
- 作者作品速览支持折叠/展开、拖动、缩放、定位当前作品、上一页/下一页、滚轮翻页、多图数量角标。
- 作者页显示独立悬浮控制栏，可调整作品列表每行数量、按最低页数隐藏作品，并支持拖动和横向宽度调整。

## 使用

1. 打开 Chrome `chrome://extensions/`。
2. 启用“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择本项目目录。
5. 打开 Pixiv 页面使用。

## 作者页显示控制

在 Pixiv 作者页（如 `/users/{id}`、`/users/{id}/artworks`、标签筛选页）会显示“作者页显示”悬浮控制栏：

- `每行`：用 `- / +` 调整作品列表每行显示数量，降低页面密度，并按比例放大已有缩略图。
- `最低页数`：输入页数阈值，隐藏页数少于该值的作品，例如输入 `2` 会隐藏单页作品。
- 控制栏可拖动，左下角拖拽手柄可从右向左调整横向宽度，位置和宽度会保存在本地。

## Popup

- `标记`：调整颜色、标题变色、图片遮罩、隐藏已访问作品。
- `排除`：输入 Pixiv 页面 URL，让该页面不渲染已访问效果。
- `备份`：导出备份、导入备份、清空记录。

## 隐私

所有记录只保存在本地浏览器 `chrome.storage.local` 中，不会上传。

`history` 权限只在用户点击初始化导入时请求，导入完成后会移除。
