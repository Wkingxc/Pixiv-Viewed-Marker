# Pixiv Viewed Marker

Chrome MV3 扩展，用本地记录标记 Pixiv 已访问作品，并增强作品页浏览体验。

## 功能

- 已访问作品标题变色。
- 可选图片遮罩。
- 可选隐藏已访问作品卡片。
- 支持从 Chrome 历史初始化导入 Pixiv 访问记录。
- 支持按 Pixiv 页面 URL 排除标记渲染，例如收藏页不变色、不遮罩、不隐藏。
- 支持 JSON 备份导出、合并导入、清空记录。
- 作品页"作者作品速览"面板**只嵌入 Pixiv 右侧栏**：扩展会等右栏出现后再渲染面板；宽屏下会顺手把右栏加宽。
- 作者作品速览支持两种模式：**滚动**（每行两列、纵向滚动、原生 lazy）/ **翻页**（`2 × 3` 网格、滚轮翻页）。
- 卡片支持鼠标中键 / Ctrl·Cmd+左键在**后台新标签**打开，普通左键一次点击即在当前标签跳转。
- 作者页显示控制在扩展 popup 的"作者页"页签，可调整作品列表每行作品数、按最低页数隐藏作品，可启用高清缩略图与悬停预览。
- 作品页控制在扩展 popup 的"作品页"页签：可一键隐藏作者其他作品横幅和评论区；下方"相关作品"子区域控制底部相关作品列表的每行作品数、最低页数和悬停预览。
- 作品页打开 popup 默认聚焦到"作品页"，作者页打开 popup 默认聚焦到"作者页"。

## 使用

1. 打开 Chrome `chrome://extensions/`。
2. 启用"开发者模式"。
3. 点击"加载已解压的扩展程序"。
4. 选择本项目目录。
5. 打开 Pixiv 页面使用。

## 作者页 / 作品页显示控制

在扩展 popup 的"作者页"页签中，可以配置 Pixiv 作者页（如 `/users/{id}`、`/users/{id}/artworks`、标签筛选页）的作品列表显示方式；"作品页"页签作用于作品页 (`/artworks/{id}`)，顶部是两个区块开关，下方"相关作品"子区域是作者页设置的精简版（无"高清缩略图"）。两份配置互相独立。

作品页 (`/artworks/{id}`) 顶部开关：

- `隐藏作者其他作品横幅`：把 Pixiv 主图下方"作者其他作品"那一整块横幅设为 `display: none` 视觉隐藏。请求和图片仍由 Pixiv 自身发起，扩展只负责藏起来。
- `隐藏评论区`：直接移除评论区整块。

相关作品（作品页底部）：

- `每行作品数`：通过 `−` / 数字 / `+` 步进按钮调整作品列表每行显示数量，列数变少时由 `zoom` 真实放大占位，分页 nav 会被自然推到下方。
- `最低页数`：输入页数阈值，隐藏页数少于该值的作品，例如输入 `2` 会隐藏单页作品。
- `悬停预览`：开关。开启后鼠标悬停作品卡片时会临时请求并展示该作品第一页的原图预览，浮层只显示图片。

作者页 (`/users/...`) 设置（与上面"相关作品"同名字段含义一致）：

- `每行作品数`、`最低页数`、`悬停预览`：同上。
- `高清缩略图`（仅作者页）：开关。开启后会尝试用 Pixiv 详情接口返回的原图作为列表卡片图；关闭后恢复 Pixiv 页面原始图片。

## 作品页作者作品速览

作品页的"作者作品速览"会嵌入 Pixiv 作品页右侧栏；在宽屏下扩展右侧栏宽度，让面板有足够展示空间。**扩展启动后会等右栏出现再渲染**，避免右栏未就绪时图片预加载失败；右栏 10 秒仍未就绪则放弃挂载。

- 模式：右上角按钮切换 `滚动` / `翻页`。
  - `滚动`：每行两列方形卡片，整体纵向滚动；图片由浏览器原生 `loading="lazy"` 按视口附近自动加载；首次进入会自动把当前作品对齐到视野中央。
  - `翻页`：`2 × 3` 网格 + 滚轮翻页，完整展示三行预览；底部 `定位` 跳回当前作品所在分页。
- 顶部展示"当前位置 N/M"或"M 件作品"。
- 中键 / Ctrl·Cmd+左键：通过扩展后台脚本调 `chrome.tabs.create` 强制后台新标签打开作品，且插入到当前标签右侧；普通左键单击在当前标签跳转。

## Popup

- `标记`：调整颜色、标题变色、图片遮罩、隐藏已访问作品。
- `作者页`：每行作品数、最低页数、高清缩略图开关、悬停预览开关（作用于作者页）。
- `作品页`：隐藏作者其他作品横幅、隐藏评论区两个开关；下方"相关作品"子区域提供每行作品数、最低页数、悬停预览（作用于作品页底部相关作品列表，不含高清缩略图）。
- `其他`：排除页面渲染、备份与迁移（导出/导入/清空记录）。

## 隐私

所有记录只保存在本地浏览器 `chrome.storage.local` 中，不会上传。

`history` 权限只在用户点击初始化导入时请求，导入完成后会移除。`tabs` 权限用于让中键点击作品速览卡片时在后台打开新标签。
