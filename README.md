# Pixiv Viewed Marker

Chrome MV3 扩展，用本地记录标记 Pixiv 已访问作品，并增强作品页浏览体验。

## 功能

- 已访问作品标题变色。
- 可选图片遮罩。
- 可选隐藏已访问作品卡片。
- 支持从 Chrome 历史初始化导入 Pixiv 访问记录。
- 支持按 Pixiv 页面 URL 排除标记渲染，例如收藏页不变色、不遮罩、不隐藏。
- 支持 JSON 备份导出、合并导入、清空记录。
- 作品页悬浮"作者作品速览"面板，`2 × 3` 网格分页浏览。
- 作者作品速览支持隐藏/打开（左下角粉色圆形入口）、缩放、定位当前作品、上一页/下一页、滚轮翻页、多图数量角标。
- 作者作品速览支持按住顶部"当前位置"文字横向拖动面板（仅水平方向）。
- 卡片支持鼠标中键 / Ctrl·Cmd+左键在**后台新标签**打开（通过扩展 `chrome.tabs.create` 强制后台，新标签插入当前标签右侧）。
- 作者页显示控制在扩展 popup 的"作者页"页签，可调整作品列表每行作品数、按最低页数隐藏作品，可启用高清缩略图与悬停预览。
- 作品页打开 popup 默认聚焦到"标记"，作者页打开 popup 默认聚焦到"作者页"。

## 使用

1. 打开 Chrome `chrome://extensions/`。
2. 启用"开发者模式"。
3. 点击"加载已解压的扩展程序"。
4. 选择本项目目录。
5. 打开 Pixiv 页面使用。

## 作者页显示控制

在扩展 popup 的"作者页"页签中，可以配置 Pixiv 作者页（如 `/users/{id}`、`/users/{id}/artworks`、标签筛选页）的作品列表显示方式：

- `每行作品数`：通过 `−` / 数字 / `+` 步进按钮调整作品列表每行显示数量，降低页面密度，并按比例放大已有缩略图。
- `最低页数`：输入页数阈值，隐藏页数少于该值的作品，例如输入 `2` 会隐藏单页作品。
- `高清缩略图`：开关。开启后会尝试用 Pixiv 详情接口返回的原图作为作者页卡片图；关闭后恢复 Pixiv 页面原始图片。
- `实验性悬停预览`：开关。开启后鼠标悬停作品卡片时会临时请求并展示该作品第一页的原图预览。

作品页悬浮的"作者作品速览"是页面内浮动面板；作者页显示控制不再使用页面内悬浮窗。

## 作品页作者作品速览

- 入口：作品页 (`/artworks/{id}`) 左下角粉色圆形按钮（位于樱花插件等其它入口上方，不会重叠）。
- 打开后：左下方展开 `2 × 3` 网格、顶部展示当前位置/作品总数、底部有翻页/定位按钮。
- 缩放：顶部 `−` / `+` 调整面板宽度档位（100% / 120% / 140%），缩放方向向左生长，不会顶到屏幕右侧。
- 横向移动：按住顶部"当前位置 N/M"文字左右拖动可以平移面板（不允许上下移动）。
- 翻页：底部按钮翻页或切换为滚轮翻页模式。
- 中键 / Ctrl·Cmd+左键：通过扩展后台脚本调 `chrome.tabs.create` 强制后台新标签打开作品，且插入到当前标签右侧。

## Popup

- `标记`：调整颜色、标题变色、图片遮罩、隐藏已访问作品。
- `作者页`：每行作品数、最低页数、高清缩略图开关、实验性悬停预览开关。
- `排除`：输入 Pixiv 页面 URL，让该页面不渲染已访问效果。
- `备份`：导出备份、导入备份、清空记录。

## 隐私

所有记录只保存在本地浏览器 `chrome.storage.local` 中，不会上传。

`history` 权限只在用户点击初始化导入时请求，导入完成后会移除。`tabs` 权限用于让中键点击作品速览卡片时在后台打开新标签。
